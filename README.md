#### 🎮 Как скачать и играть

Установка дополнительных программ не требуется — всё необходимое уже собрано в одном архиве. 

1. Перейдите в раздел **Релизы (Releases)** справа на странице репозитория.
2. Скачайте ZIP-архив **Space Miner Clicker** из последнего релиза.
3. Распакуйте архив в любую удобную папку.
4. Запустите файл main.exe двойным кликом и наслаждайтесь игрой!

#### 🔄 Как обновить игру (одноразовая настройка)

Вам не нужно каждый раз заново скачивать ZIP-архив с игрой или заново загружать updater — достаточно скачать **один раз**, чтобы получать обновления в один клик и **не терять свой прогресс**: 

1. Скачайте файл updater.exe из репозитория (подойдёт любая версия — программа сама найдёт самый свежий релиз).
2. Поместите updater.exe в папку с игрой (рядом с main.exe) и оставьте его там.
3. При выходе новых версий просто запускайте этот updater.exe из папки с игрой и нажимайте кнопку **«Обновить»**.
4. Дождитесь завершения загрузки — все ваши сохранения останутся на месте. Нажмите **«Играть»** и наслаждайтесь актуальной версией!

🛡️ **Примечание по безопасности:** При первом запуске main.exe или updater.exe система Windows SmartScreen или антивирус может выдать предупреждение о неизвестном файле. Это стандартное ложное срабатывание для инди-проектов без дорогостоящей цифровой подписи. Файлы полностью безопасны — просто нажмите **«Подробнее» → «Выполнить в любом случае»** (или добавьте папку с игрой в исключения антивируса).
