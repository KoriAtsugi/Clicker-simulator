# 🚀 Space Miner Clicker

Космический кликер-симулятор с системой престижа, экспедициями и экзотической материей.

---

## 🎮 Как скачать и играть

Установка дополнительных программ не требуется — всё необходимое уже собрано в одном файле.

1. Перейдите в раздел **Релизы** справа на странице репозитория.
2. Скачайте файл **`main.exe`** из последнего релиза.
3. Создайте папку для игры (например, `SpaceMiner`) и поместите туда `main.exe`.
4. Запустите `main.exe` двойным кликом и наслаждайтесь игрой!

---

## 🔄 Как обновлять игру (одноразовая настройка)

Вам не нужно каждый раз заново скачивать игру — достаточно **один раз** настроить updater, чтобы получать все будущие обновления в один клик и **не потерять свой прогресс**:

1. Скачайте файл **`updater.exe`** из репозитория (подойдёт любая версия — программа сама найдёт самый свежий релиз).
2. Поместите `updater.exe` **в ту же папку**, где лежит `main.exe`.
3. При выходе нового обновления просто запустите `updater.exe` из папки с игрой и нажмите кнопку **«Обновить»**.
4. Дождитесь завершения загрузки — все ваши сохранения останутся на месте. Нажмите **«Играть»** и наслаждайтесь актуальной версией!

> 💡 **Важно:** в дальнейшем новые файлы из релизов скачивать не нужно — `updater.exe` сам обновит игру до последней версии.

---

## 🛡️ Примечание по безопасности

При первом запуске `main.exe` или `updater.exe` система Windows SmartScreen или антивирус может выдать уведомление о неизвестном файле. Это стандартное ложное срабатывание для инди-проектов без дорогостоящей цифровой подписи. Файлы полностью безопасны — просто нажмите **«Подробнее» → «Выполнить в любом случае»** (или добавьте папку с игрой в исключения антивируса).
